# 마우스 모션 프로파일 사용법

## 기본 프로파일 선택

상단 **마우스** 메뉴에서 **앱 기본 모션 프로파일** 또는 **프로젝트 기본 모션 프로파일**을 선택합니다. 앱의 초기 기본값은 **Natural**입니다. 프로젝트에 별도 값을 지정하지 않으면 앱 기본값을 사용합니다. 블록에서 프로파일을 직접 지정하면 프로젝트보다 우선합니다.

| 프리셋 | 움직임 |
|---|---|
| Direct | 속도가 부드럽게 변하는 직선 이동 |
| Precision | 작은 속도 변화와 작은 횡방향 흔들림 |
| Smooth | 완만한 속도와 방향 편차 |
| Natural | 중간 강도의 속도 변화와 횡방향 흔들림 |
| Tremor | 흔들림이 두드러지는 이동 |

**모션 프로파일 관리**에서 새 프로파일을 만들거나 기존 프로파일을 복제합니다. 기본 탭에서 이동 시간, 속도 변화 강도, 횡방향 흔들림을 조절합니다. 고급 탭에서 샘플링, 상관 시간, 드리프트와 시드 정책을 설정합니다. 내장 프리셋을 편집하려면 먼저 복제하세요.

앱이나 현재 프로젝트에서 사용 중인 사용자 프로파일을 삭제하려면 해당 기본값이나 블록 선택을 먼저 바꾸세요. 프로젝트에 저장한 사용자 프로파일은 해당 버전의 복사본과 함께 저장됩니다. 로컬 사본을 수정한 뒤 프로젝트 기본값에 반영하려면 **최신 버전 적용**을 선택합니다.

## Blockly에서 이동시키기

1. **마우스** 팔레트에서 모션 프로파일을 고를 수 있는 이동 블록을 꺼냅니다.
2. 절대 이동에는 도착할 화면 좌표를 연결합니다. 상대 이동에는 실행 시 커서 위치에서 더할 X·Y 값을 연결합니다. 양수 X는 오른쪽, 양수 Y는 아래쪽입니다.
3. 시간을 연결하면 프로파일 기본 시간보다 우선합니다. 시간을 비우면 프로파일에 저장된 시간을 사용합니다.
4. **프로젝트 기본값**을 따르거나 블록에서 별도 프로파일을 선택합니다.
5. **검증**을 누르고 드라이런에서 이동 기록을 확인합니다.

예제 프로젝트는 첫 이동에서 프로젝트 기본값을 사용하고, 다음 상대 이동에는 Direct를 지정합니다. 출력 방식은 드라이런입니다. [예제 프로젝트](../examples/mouse_motion_showcase.macroproj)

기존 프로젝트의 프로파일 선택란이 없는 이동 블록은 기존 직선 이동을 사용합니다. 프로파일을 지정하려면 새 이동 블록을 사용하세요.

## 궤적 미리보기

**마우스 → 궤적 미리보기**를 열면 현재 기본 프로파일의 예상 경로와 종방향·전체 속도가 나타납니다. 관리 창에서는 선택한 프로파일을 바로 미리 볼 수 있습니다. 좌표, 시간, 샘플링을 여기서 바꿔도 저장된 프로파일에는 반영되지 않습니다.

- **시드 고정**을 켜고 같은 값을 입력하면 동일한 조건에서 같은 궤적을 재현합니다. **새 시드로 다시 생성**은 표시된 시드를 새 값으로 바꿉니다.
- **재생**, **일시정지**, **처음부터**는 그래프 안의 가상 커서를 제어합니다. 실제 포인터는 움직이지 않습니다.
- 이전 궤적과 비교하려면 시작점과 목표점을 같게 두세요. 흔들림 표시 배율은 그래프에만 적용됩니다.

## 실입력과 정지

SendInput 또는 External HID를 선택하고 프로젝트를 ARM한 뒤 대상 창을 지정하세요. External HID에서는 **Streaming** 또는 **Adaptive**를 사용합니다. Leonardo는 상대 이동 보고서를 받습니다. 보고서의 논리 변위 합계는 보존되지만 실제 도착 좌표는 Windows 포인터 가속과 화면 경계의 영향을 받습니다.

한 Task가 포인터를 쓰는 동안 경쟁 이동은 거부됩니다. 우선 실행 정책이 진행 중인 작업을 선점하면 기존 궤적을 취소하고 현재 커서 위치에서 새 이동을 시작합니다. 편집기에서 프로파일을 바꾼 내용은 다음 실행 세션부터 적용됩니다. 정지나 포커스 이탈이 발생하면 남은 이동을 취소합니다. 긴급 정지의 기본 키는 **Ctrl+Alt+Shift+F11**입니다.

실기기 확인 범위와 계측 조건은 [v1.2 인수 검증](MOUSE_MOTION_ACCEPTANCE.md)에서 확인할 수 있습니다.
