# Blockly와 Python 왕복 변환 계약

Blockly와 Python 양쪽에서 표현할 수 있는 부분집합의 실행 의미를 공통 IR로 비교한다. PY-3은 [변환 API](../src/macro_studio/python_roundtrip.py)를 제공한다. 변환이 실패하면 원본 프로젝트를 수정하지 않으며, 가능한 경우 원본 블록 ID나 소스 범위와 실패 이유를 반환한다. PY-4는 편집 화면의 모드 전환, 초안 보존과 별도 작업에서의 변환 검증을 연결한다.

## 변환 가능성 매트릭스

| 기존 IR과 블록 | 왕복 목표 | 검증할 의미 |
|---|---|---|
| 시작, 핫키, 간격, 워크플로 정의·호출 | 지원 | 이벤트 값, 우선순위, 재진입 정책, 타입 있는 인자. 가드와 반환값은 후속 범위다. |
| 조건, 대입, 반복, `break/continue`, `wait/end` | 공통 부분집합 지원 | 변수 범위, 문장 순서, 분기·반복 상한, 시간 단위와 취소 의미 |
| 키 누르기·연타, 마우스 클릭, `mouse_move_timed` | 논리 키, ms 단위, 절대 좌표 프로파일 이동 지원 | 논리 키, 시간, 반복 주파수, 좌표 공간, 모션 프로파일 스냅샷, 필요한 출력 기능 |
| `vision_find`, `vision_wait`, `vision_result` | 표준 API가 표현하는 형태 지원 | 템플릿 ID, 탐지 설정, 결과 바인딩, 타임아웃, 프레임 신선도, `FOUND/NOT_FOUND/UNKNOWN` |
| 인식 이벤트·가시성·HSV, 사용자 이벤트, 상태 머신, 레거시 센서, `timed_batch` | 각 계약을 표현하는 DSL 구문과 반대 방향 렌더러가 생길 때 지원 | 미지원 구성을 만나는 즉시 변환 실패 |
| Python의 지역 변수, 루프 인덱스, 복합 결과 값 | 기존 IR과 양쪽 편집 표현에서 의미를 보존할 수 있는 형태 지원 | 공유 전역 변수로 바꿔 동시 작업의 상태를 섞지 않는다. |

## 의미 비교 기준

1. 원본과 변환본을 각각 해당 컴파일러로 컴파일한 뒤 `validate_program`을 통과시킨다. Blockly의 분리된 블록은 실행 IR 비교와 별도로 진단한다.
2. 객체 키 순서, Python 서식, Blockly 배치, 표시용 소스 위치를 비교에서 제외한다. 숫자는 IR이 검증한 타입과 단위로 비교한다. 서로 다른 수치나 좌표를 반올림해 같은 값으로 만들지 않는다.
3. 자동 생성 ID가 달라지면 일대일 대응을 만들고 참조도 함께 치환한다. 사용자에게 노출되는 프로젝트·템플릿·프로파일·서비스 ID와 명시적 심볼은 보존한다. 핸들러와 명령 배열 순서는 유지한다.
4. 이벤트 종류와 핫키, 우선순위와 재진입, 변수·호출 바인딩, 반복·시간, 인식 설정, 모션 프로파일 및 출력 Capability, 실패·취소·분기를 비교한다.
5. 같은 가상 시각과 동일한 인식 결과를 주입하고 Fake 출력의 동작·순서·예약 시각과 종료 상태를 비교한다. 서비스 오류와 오래된 프레임 사례도 같은 규칙으로 검사한다.

## 소스맵과 실행 스냅샷

기존 `block_id`와 Python AST의 시작·끝 줄과 열은 별도 소스맵에 보관한다. Python의 값은 AST의 1부터 시작하는 줄과 0부터 시작하는 UTF-8 바이트 열을 기준으로 저장한다. UI가 사용자에게 표시할 때 문자 위치로 변환한다. 생성 ID는 선언 식별자와 노드의 구조를 바탕으로 재현하며, 줄 번호만으로 정하지 않는다.

fingerprint는 활성 모드의 현재 소스와 컴파일에 영향을 주는 프로젝트 자산·프로파일·서비스 설정을 확인하는 데 사용한다. 로드 후에는 다시 검증한다. 실입력 허가는 기존 ARM과 출력 세션 정책을 따른다. Python 변환 코드와 직접 실행할 수 없는 예제는 PY-3 인수 테스트에서 검증한다.

`generate_python(program, project)`은 검증된 IR과 대상 프로젝트에서 정형 소스와 블록 ID 대응을 만든다. 반환 객체의 `compile(project)`는 이 대응을 적용해 핸들러와 실행 블록 ID를 복구한다. `render_blocks(program, project)`는 동일한 프로젝트에서 열 수 있는 워크스페이스 JSON을 반환한다. 프로젝트의 전역 변수와 에셋·프로파일은 기존 프로젝트에 저장한다. 두 API 모두 변환 결과를 재컴파일하고 의미 비교를 통과한 경우에만 반환한다.
