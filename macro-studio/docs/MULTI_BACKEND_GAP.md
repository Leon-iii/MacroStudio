# Macro Studio v1.1 멀티 출력 구현 현황

기존 v1 코어에는 IR 검증, Blockly 편집기, 별도 Runner, Fake, Windows SendInput, 화면 센서와 실행 디버거가 있다. Runtime은 스케줄링과 키·마우스 버튼 소유권 및 정지 시 해제를 관리한다. v1.1은 이 실행 흐름에 외부 HID 출력 채널과 장치 세션을 추가한다.

| 범위 | 현재 상태 | 후속 작업 |
|---|---|---|
| 출력 경로 | CLI와 편집기에서 Fake와 SendInput을 출력 라우터로 선택한다. 드라이런은 Fake를 사용한다. | 외부 HID 경로를 등록하고 실행 단위로 장치 세션을 연결한다. |
| 장치 프로토콜 | COBS, CRC-16, 메시지 및 세션 필드, 스트림 파서를 구현했다. | 동일한 바이트 형식으로 Leonardo 펌웨어를 구현한다. |
| 포트 | 전송 계층이 한 번에 요청 하나를 추적하고 세션 ID, 순번, 응답과 타임아웃을 확인한다. | 선택한 COM 포트의 I/O worker, heartbeat와 장치 해제를 연결한다. |
| 가상 MCU | 실제 장치 없이 프레임 응답과 장치 측 입력 상태를 검증할 수 있다. | 펌웨어와 공유하는 테스트 벡터로 실기기 동작을 비교한다. |
| 키와 마우스 | SendInput과 Fake는 기존 IR을 사용한다. 가상 MCU는 키, 버튼, 상대 이동을 지원한다. | HID Usage 변환, 좌표 보정, 포커스 재확인, MCU 출력 제한을 연결한다. |
| 프로필과 장치 UI | 기존 대상 창과 ARM 설정을 사용한다. | 출력 선택, 포트 선택, 연결 상태, 프로필 저장과 오류 표시를 추가한다. |

외부 HID를 실제로 출력하는 시점에 Windows 및 Leonardo에서 포커스 상실, 긴급 정지, 포트 분리, watchdog, 재연결을 검증한다.
