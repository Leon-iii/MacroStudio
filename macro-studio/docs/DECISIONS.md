# Phase 0 결정 기록

- 표준 라이브러리로 IR을 검증하고, 명령과 식을 명시적으로 해석한다. 파일에는 실행할 Python 코드가 들어가지 않는다.
- 여러 Task는 같은 이벤트 루프와 가상 시계를 사용한다. 키 소유권과 전역 상태 변경은 같은 루프에서 처리한다.
- 한 세션은 동시 Task를 256개까지 허용한다. Task는 명령과 반복 진행을 합쳐 256회마다 가상 시간 1ms를 양보한다. 대기 없는 반복 중에도 종료 요청과 이후 모의 이벤트를 처리할 수 있다.
- 워크플로 호출 깊이는 32까지 허용한다. 런타임은 블록 중첩과 워크플로 호출을 자체 스택에 저장한다.
- `--duration-ms` 경계에서 정지와 키 해제를 먼저 처리한다. 경계에 예약된 새 입력이나 핫키는 실행하지 않는다.
- 드라이런은 핫키 이벤트를 입력 데이터로 전달한다. Windows 세션은 운영체제에 조합형 핫키를 등록한다. 실입력 직전에는 눌려 있는 수정 키를 포함해 핫키 재발동을 검사한다.
- Windows는 F12를 디버거용으로 예약한다. 긴급정지 기본값은 Ctrl+Alt+Shift+F11이며, CLI의 재개는 Ctrl+Alt+Shift+F10을 사용한다.
- Win32 `SendInput`은 포그라운드 입력 스트림에 삽입한다. 포커스 확인과 호출은 개별 API이므로 두 호출 사이의 포커스 변경을 원자적으로 차단할 수 없다.

## v1.1 멀티 출력

- **ADR-008 — 출력 채널과 실행 장소 분리.** HID Streaming에서도 PC 스케줄러가 입력 시점을 결정한다. 출력 채널과 HID 실행 모드는 각각 프로필에 기록한다.
- **ADR-009 — 실행마다 출력 채널 고정.** 드라이런은 Fake에 연결한다. 실제 출력은 ARM과 사용 가능한 경로가 있어야 하며, 실행 중 채널 전환과 자동 폴백을 금지한다. 경로를 만들기 전에 중첩 블록을 포함해 필요한 기능을 검사한다.
- External HID 세션 종료 뒤 장치 해제 응답을 확인하지 못한 키와 버튼은 Windows 해제 이벤트로 정리한다. 이 경로는 해제만 보내며 워크플로를 종료한다.
- **ADR-010 — 장치 독립 IR.** 현재 IR과 Runtime의 입력 소유권·해제 규칙을 사용한다. 외부 HID 코드는 별도 계층에서 Windows 논리 키를 HID Usage로 변환한다.
- **ADR-011 — HID 단계별 구현.** Streaming을 먼저 구현한다. Timed Batch와 MCU Onboard 작업은 후속 단계에서 장치 기능을 확인한 뒤 지원한다.
- 좌표 기반 외부 HID 동작은 PC가 실제 커서 위치를 읽고 목표까지 남은 상대 이동을 계산한다. 보정 횟수와 시간을 제한하고, 클릭 직전에 목표 도달과 포커스를 확인한다. 보정 실패나 포커스 상실 시 클릭을 취소한다.
